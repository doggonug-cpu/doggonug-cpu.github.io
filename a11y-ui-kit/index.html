Why senior UI is a different problem

Most design systems are tuned for a 25-year-old thumb. This one moves the baseline.

01

Sized for a shaking hand

A 48px floor, 56–64px for primary actions, 12px between targets — above the 44px that WCAG 2.5.5 (AAA) requires.

02

Readable when eyes blur

Body text at 18.4:1 and secondary text at 10.6:1, past the 7:1 AAA bar. State never relies on colour alone — icon and sentence come with it.

03

Feedback you can hear

A 40 ms tone synthesized with Web Audio. No mp3, no download. Sound can be switched off, and every cue is mirrored by visible text and a screen-reader announcement.

04

Correct by construction for AI

The MCP server hands your agent the code, the implementation prompt and the WCAG checklist directly, so it stops guessing from memory.

local stdio · nothing leaves your machine

An MCP server, not a PDF.

Your agent asks for the code, the implementation prompt or the WCAG checklist and gets it — no network calls, no API keys.

Server source

Four tools

list_components
Filter all 18 by tier, tag or keyword. Each row carries its WCAG criteria and status.
get_component
Returns HTML+CSS+JS, React source and accessibility notes for one id. Pro ids return the spec and a lock notice, never the source.
get_ai_prompt
Builds a paste-ready prompt for Claude Code, Cursor or Lovable.
check_wcag_checklist
Returns the criteria that apply, with the manual check a human must run for each.

Needs Node 18+. The server talks over stdio only and only reads its own data file.

Questions

Is the free tier really MIT?

Yes. The ten free components are published under MIT — copy them into commercial products, no attribution required. Pro source is separately licensed and only released to buyers.

Do I need a build step?

No. The HTML+CSS+JS version runs as one file, and the React version is a single-file component. This site itself ships with no framework, bundler or external script.

Is this site itself WGAC AAA?

Body text measures 18.4:1 and secondary text 10.6:1, past the 7:1 AAA bar; every control is at least 48px with a 4px focus ring. We do not claim automated AAA conformance for the whole page — AAA includes criteria such as sign-language and image-text levels that need a human review.

Is the MCP server safe to run?

It speaks over stdio only, reads one local `catalog.json` beside it, and makes no network requests, writes no files and needs no API keys. The source is public so you can read it first.

What about Korean?

Every component ships Korean and English label sets, and this page switches between EN and KO. The multilingual voice pack is part of Pro.

Does it work without sound?

All sound is optional. The switch in the header turns it off and remembers the choice; the same information is always carried by visible text and a screen-reader announcement.

Can I pay now?

Not yet. Until settlement is connected the buttons collect an early-access request instead. The list hears first when checkout opens, and nothing is charged before that.

Can agencies and care providers use it?

The free ten already are. If you apply these across client sites or need kiosk and care flows, Pro fits; note your team size in the list form and a team licence will be offered when checkout opens.
